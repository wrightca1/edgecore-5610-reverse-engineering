# Files now captured (at `cumulus_baseline_2013_run2/final_gaps_20260513_202013/`)

## `/var/lib/cumulus/rc.datapath_0` — THE actual chip-init datapath script
371 lines, 223 non-comment bcmcmd ops. Loaded by `rc.soc` via `rcload`. Generated by `update-ports` from `/etc/cumulus/ports.conf`. Sets up:

- **Ingress buffer pools**: 4 service pools, pool 1 limit 1382 cells, pool 2 limit 921, shared 22742
- **Per-priority-group min/shared limits**: `pg_min_cell[0].cpu0=45`, `pg_min_cell[0].xe48-xe51=1152`, `pg_min_cell[0].xe0-xe47=288`
- **Egress queue pools**: same sizes per uc/mc/cpu queues
- **PFC/pause defaults**: disabled (`pfc_enable=0`, `rx_pfc_en=0`, `tx_pfc_en=0`)
- **CoS→PG mappings**: pri7→grp7 (control), pri2→grp2 (service), rest→grp0 (bulk)
- **Color awareness**: disabled
- **Drop counter selects**: `rdbgc0_select 0x04000d11` etc (from rc.soc)

This file is THE missing piece for EdgeNOS's chip init — without buffer pool setup, the chip can't even queue packets.

## `/usr/lib/cumulus/update-ports` — Python script (232 lines)
Generator for `rc.datapath_0` + `config.bcm` from `/etc/cumulus/ports.conf` (a port-count + speed config). Reading this Python source teaches us the exact logic Cumulus uses to compute buffer sizes for a given chip variant.

## `/etc/cumulus/acl/policy.d/00control_plane.rules` — Control-plane traps
Iptables-style rules that drive the chip's FP/ACL TCAM. Tells EdgeNOS exactly which protocols Cumulus traps to CPU:
- **OSPF** (proto 89) — class 7, 2000 pkts/s rate-limit
- **BGP** (tcp dport 179) — class 7, 2000 pkts/s
- **CLAG** (tcp port 5342) — class 7, 2000 pkts/s
- **ICMP** — class 2, 100 pkts/s
- **BOOTP/DHCP** — class 2, 100 pkts/s
- **Martian sources** (240/5, 127/8, 224/8, 255.255.255.255/32) — dropped
- All hit `ingress chain` on `swp+` interfaces

EdgeNOS needs equivalent FP rules to properly trap OSPF hellos, BGP keepalives, ICMP echo-replies, etc. to CPU.

# ECMP format — also decoded this pass
`l3 multipath show` output:
```
Multipath Egress Object 200000
Interfaces: 100004 100003       # chip-side INTF id 4, 3 (= swp2, swp1 single-NH objects)
Reference count: 27             # 27 routes use this ECMP group
```

`dump L3_ECMP`:
```
L3_ECMP[0]: NEXT_HOP_INDEX=4, NEXT_HOP=4   # half 0 = INTF 4 (swp2)
L3_ECMP[1]: NEXT_HOP_INDEX=3, NEXT_HOP=3   # half 1 = INTF 3 (swp1)
L3_ECMP[2..]: all zero (unused)
```

Routes in `L3_DEFIP` that use ECMP set the `ECMP*` fields to point at this group's base index. Chip hashes per-flow to pick a member.
